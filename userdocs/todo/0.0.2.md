### 6. Автодетекция Anthropic моделей в ChatOpenRouter (КРИТИЧНО)

**Файл:** `browser_use/llm/openrouter/chat.py`

**Задачи:**
- [ ] Добавить метод `_is_anthropic_model()` для детекции Anthropic моделей
- [ ] Обновить метод `ainvoke()` для автоматического применения `remove_validation_constraints=True` для Anthropic
- [ ] Добавить опциональный параметр `anthropic_compatible_mode: bool = False` для ручного управления

**Принципы:**
- First Principles: Решаем проблему автоматически, пользователь не должен думать об этом
- SOLID: Open/Closed - расширяем функциональность без изменения существующего API

**Код изменений:**
```python
@dataclass
class ChatOpenRouter(BaseChatModel):
    model: str
    ...
    anthropic_compatible_mode: bool | None = None  # None = auto-detect

    def _is_anthropic_model(self) -> bool:
        """Detect if model is from Anthropic"""
        model_lower = self.model.lower()
        return 'anthropic' in model_lower or 'claude' in model_lower

    async def ainvoke(self, messages, output_format=None):
        if output_format is not None:
            # Auto-detect or use explicit setting
            is_anthropic = (
                self.anthropic_compatible_mode
                if self.anthropic_compatible_mode is not None
                else self._is_anthropic_model()
            )

            if is_anthropic:
                schema = SchemaOptimizer.create_optimized_json_schema(
                    output_format,
                    remove_validation_constraints=True,
                    remove_min_items=True,
                    remove_defaults=True,
                )
            else:
                schema = SchemaOptimizer.create_optimized_json_schema(output_format)
```
