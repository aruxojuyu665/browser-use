## Риски и ограничения

### Известные риски:
1. **Rate limiting** - GitHub API может ограничить запросы без авторизации
2. **Latency** - OpenRouter proxy добавляет ~500-1000ms overhead
3. **Model availability** - модели могут быть временно недоступны
4. **Cost** - deep research использует много токенов (ожидается $0.05-0.20 за тест)
5. **Timeout** - длинные тесты могут превышать таймауты

### Митигация:
- Использовать Automatic Fallback для обхода недоступности
- Мониторить стоимость в реальном времени через Cost Estimation
- Ограничить количество шагов агента (max_steps=20)
- Увеличить таймауты для сложных запросов
- Использовать prompt caching где возможно
