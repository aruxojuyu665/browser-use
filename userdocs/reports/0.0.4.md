## Executive Summary

Version 0.0.4 introduces automatic model fallback and comprehensive metrics tracking for the OpenRouter integration. These features enable more resilient LLM operations and provide visibility into usage, costs, and performance.

**Key Achievements:**
- Automatic fallback between models when primary model fails
- Built-in metrics tracking with cost estimation
- Prometheus export support for monitoring systems

## Changes Overview

### 1. Automatic Fallback Between Models (P1)

**File:** `browser_use/llm/openrouter/chat.py`

**Features:**
- New parameter `fallback_models: list[str]` - list of backup models to try
- New parameter `on_fallback: Callable` - callback for fallback notifications
- New property `active_model` - returns currently active model after potential fallback
- Automatic retry with next model on: RateLimitError, APIConnectionError, APIStatusError

**Implementation:**
```python
llm = ChatOpenRouter(
    model='anthropic/claude-4.5-sonnet',
    fallback_models=['anthropic/claude-3.5-sonnet', 'openai/gpt-4o'],
    on_fallback=lambda from_m, to_m, err: print(f"Fallback: {from_m} -> {to_m}"),
    api_key=key,
)
```

**Technical Details:**
- Fallback chain is tried in order: primary -> fallback[0] -> fallback[1] -> ...
- Each model gets proper schema optimization based on its provider
- Fallback events are logged via standard Python logging
- Callback is invoked with (from_model, to_model, error) signature

### 2. Monitoring and Metrics (P2)

**New File:** `browser_use/llm/metrics.py`

**Classes:**
- `RequestMetrics` - metrics for a single LLM request
- `ModelPricing` - pricing information for cost calculation
- `LLMMetrics` - aggregate metrics with cost estimation

**Features:**
- Request counting (total, successful, failed, fallbacks)
- Token tracking (prompt, completion, cached)
- Latency measurement (average per successful request)
- Cost estimation based on known model pricing
- Per-model breakdown
- Export to JSON and Prometheus formats

**Integration with ChatOpenRouter:**
```python
llm = ChatOpenRouter(
    model='anthropic/claude-4.5-sonnet',
    api_key=key,
    track_metrics=True,  # Enable metrics
)

# After requests
metrics = llm.get_metrics()
print(f"Cost: ${metrics.cost_estimate_usd:.4f}")
print(f"Avg latency: {metrics.average_latency_ms:.1f}ms")
```

### 3. Cost Estimation (P2)

**Included in:** `browser_use/llm/metrics.py`

**Features:**
- Known pricing for common models (Anthropic, OpenAI, Google, DeepSeek)
- Custom pricing overrides via `set_pricing()`
- Cached token pricing support
- Quick access via `llm.get_estimated_cost()`

**Pricing Database:**

## Technical Implementation

### Architecture Decisions

**First Principles Applied:**
1. **Resilience by default** - fallback is opt-in but zero-config when enabled
2. **No runtime overhead when disabled** - metrics only collected if `track_metrics=True`
3. **Composability** - external metrics instance can aggregate across multiple clients

**SOLID Principles:**
1. **Single Responsibility**: LLMMetrics handles all metrics, ChatOpenRouter handles invocation
2. **Open/Closed**: Extended without modifying existing API surface
3. **Dependency Inversion**: Metrics module has no dependencies on ChatOpenRouter

**KISS Principle:**
- Simple list-based fallback chain
- Boolean flag to enable metrics
- Property access for common operations

### Code Structure

**browser_use/llm/openrouter/chat.py:**

## Usage Examples

### Example 1: Fallback with Callback

```python
from browser_use.llm import ChatOpenRouter
import os

def log_fallback(from_model, to_model, error):
    print(f"[WARN] Model {from_model} failed, switching to {to_model}")
    print(f"       Error: {error}")

llm = ChatOpenRouter(
    model='anthropic/claude-4.5-sonnet',
    fallback_models=['anthropic/claude-3.5-sonnet', 'openai/gpt-4o'],
    on_fallback=log_fallback,
    api_key=os.getenv('OPENROUTER_API_KEY'),
)
```

### Example 2: Metrics Tracking

```python
from browser_use.llm import ChatOpenRouter
import os

llm = ChatOpenRouter(
    model='anthropic/claude-4.5-sonnet',
    api_key=os.getenv('OPENROUTER_API_KEY'),
    track_metrics=True,
)

# After some requests...
metrics = llm.get_metrics()
print(f"Requests: {metrics.total_requests}")
print(f"Tokens: {metrics.total_tokens}")
print(f"Avg Latency: {metrics.average_latency_ms:.1f}ms")
print(f"Estimated Cost: ${metrics.cost_estimate_usd:.4f}")
```

### Example 3: Shared Metrics Across Clients

```python
from browser_use.llm import ChatOpenRouter
from browser_use.llm.metrics import LLMMetrics

shared_metrics = LLMMetrics()

llm_fast = ChatOpenRouter(
    model='anthropic/claude-3.5-haiku',
    api_key=key,
    metrics=shared_metrics,
)

llm_powerful = ChatOpenRouter(
    model='anthropic/claude-4.5-sonnet',
    api_key=key,
    metrics=shared_metrics,
)

# All requests aggregate to shared_metrics
print(f"Combined usage: ${shared_metrics.cost_estimate_usd:.4f}")
```
