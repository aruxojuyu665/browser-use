### 1.2 LLM Metrics Tracking

**Локация:** [browser_use/llm/metrics.py](browser_use/llm/metrics.py)

#### Архитектура

**Основные классы:**

1. **`RequestMetrics`** (строки 12-48): Метрики одного запроса
   - Pydantic BaseModel с `extra='forbid'`
   - Поля: model, tokens, latency, success, error, fallback info, cached tokens
   - Timestamp для временных меток

2. **`ModelPricing`** (строки 51-64): Информация о ценах
   - Цена за миллион токенов (prompt/completion)
   - Поддержка cached token pricing

3. **`KNOWN_MODEL_PRICING`** (строки 68-83): База данных цен
   - Anthropic models: Claude 4.5 Sonnet, 3.5 Sonnet, 3.5 Haiku
   - OpenAI models: GPT-4o, GPT-4o-mini, o1-preview
   - Google models: Gemini 2.0 Flash, 2.5 Pro
   - DeepSeek models: DeepSeek Chat

4. **`LLMMetrics`** (строки 86-382): Агрегатор метрик
   - Сбор и хранение метрик запросов
   - Подсчет токенов, латентности, ошибок
   - Оценка стоимости
   - Экспорт в dict и Prometheus формат

#### Детальный обзор функциональности

**Сбор метрик:**
```python
def record_request(self, request: RequestMetrics) -> None:
    """Record a completed LLM request."""
    self._requests.append(request)
    self.total_requests += 1

    if request.success:
        self.successful_requests += 1
        self.total_prompt_tokens += request.prompt_tokens
        self.total_completion_tokens += request.completion_tokens
        self.total_cached_tokens += request.cached_tokens
    else:
        self.failed_requests += 1
```

**Оценка стоимости:**
- Использует базу `KNOWN_MODEL_PRICING`
- Учитывает cached tokens с отдельным pricing
- Расчет: `(tokens / 1_000_000) * price_per_million`
- Поддержка кастомного pricing через `set_pricing()`

**Экспорт данных:**
- `to_dict()`: JSON-совместимый словарь
- `to_prometheus()`: Метрики в формате Prometheus
- `get_model_breakdown()`: Статистика по каждой модели

**Статический анализ:** ✅ PASS

**Качество кода:** 10/10

**Сильные стороны:**
- Отличная документация с примерами использования

### 1.3 Cost Estimation

**Интеграция с ChatOpenRouter:**

```python
def get_estimated_cost(self) -> float:
    """Get the estimated cost in USD for all tracked requests."""
    if self.metrics is None:
        return 0.0
    return self.metrics.cost_estimate_usd
```

**Механизм работы:**

1. При `track_metrics=True` создается экземпляр `LLMMetrics`
2. После каждого успешного запроса записываются метрики через `_record_metrics()`
3. Метрики включают: model name, tokens, latency
4. `cost_estimate_usd` property вычисляет стоимость на основе:
   - `KNOWN_MODEL_PRICING` database
   - Фактического использования токенов
   - Различных цен для prompt/completion/cached токенов

### 2.3 Schema Optimization

**Метод:** `_get_schema_for_model()`

Автоматически оптимизирует JSON Schema в зависимости от провайдера:

```python
def _get_schema_for_model(self, output_format: type[BaseModel], model_name: str) -> dict[str, Any]:
    if self.anthropic_compatible_mode is True:
        # Explicitly force Anthropic mode
        return SchemaOptimizer.create_schema_for_provider(output_format, ProviderType.ANTHROPIC)
    elif self.anthropic_compatible_mode is False:
        # Explicitly use full schema
        return SchemaOptimizer.create_optimized_json_schema(output_format)
    else:
        # Auto-detect based on model name (default)
        return SchemaOptimizer.create_schema_for_provider(output_format, model_name)
```

**Результаты:** ✅ PASS
- Правильная логика auto-detection
- Поддержка ручного override через `anthropic_compatible_mode`
