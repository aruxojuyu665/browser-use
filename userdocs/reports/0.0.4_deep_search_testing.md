## Тестовое окружение

### Конфигурация

- **Версия browser-use:** 0.9.7 (доступна 0.10.1)
- **Python:** 3.12
- **OS:** Windows
- **Провайдер:** OpenRouter API
- **Primary Model:** anthropic/claude-3.5-sonnet
- **Fallback Models:** openai/gpt-4o, google/gemini-2.0-flash-exp:free
- **Metrics Tracking:** Enabled
- **Max Steps:** 5-10 (в зависимости от теста)

### Настройки агента

```python
llm = ChatOpenRouter(
    model='anthropic/claude-3.5-sonnet',
    fallback_models=['openai/gpt-4o', 'google/gemini-2.0-flash-exp:free'],
    track_metrics=True,
    on_fallback=lambda from_m, to_m, err: logger.warning(
        f"Fallback: {from_m} -> {to_m} (reason: {err})"
    ),
    api_key=os.getenv('OPENROUTER_API_KEY'),
)

agent = Agent(
    task=query,
    llm=llm,
    max_steps=10,
    use_vision=False,
)
```
